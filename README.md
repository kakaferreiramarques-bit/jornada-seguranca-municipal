# Jornada de Segurança da Informação

Protótipo acadêmico de roteiro gamificado para autoverificação de práticas de segurança da informação por servidores públicos municipais.

## Como executar

1. Extraia a pasta.
2. Abra a pasta `roteiro-seguranca` no VS Code.
3. Abra o arquivo `index.html`.
4. Clique com o botão direito no arquivo e escolha "Open with Live Server", se você tiver a extensão Live Server instalada.
5. Alternativamente, abra `index.html` diretamente no navegador.

## Estrutura

- `index.html`: página principal.
- `css/estilo.css`: aparência e responsividade.
- `js/app.js`: perguntas, missões, pontuação, feedback e recomendações.

## O que já está implementado

- tela inicial;
- diagnóstico inicial;
- mapa de 5 missões;
- 15 situações-problema;
- decisões com consequências;
- feedback imediato;
- pontuação;
- desempenho por tema;
- microlições;
- recomendações adaptativas;
- barra de progresso;
- salvamento local no navegador com `localStorage`;
- possibilidade de retomar uma jornada interrompida;
- tela final de resultados;
- layout responsivo para computador e celular.

## Temas

1. Senhas e autenticação
2. Phishing e engenharia social
3. Atualizações e dispositivos
4. Privilégios e contas
5. Comunicação e incidentes

## Observação acadêmica

Este protótipo é uma prova de conceito. As orientações de segurança devem ser revisadas e adaptadas às políticas, procedimentos, normas e canais oficiais da instituição que utilizar o sistema.

A próxima evolução pode incluir:
- login;
- banco de dados;
- painel administrativo;
- histórico de participantes;
- autenticação;
- novas trilhas;
- desafios desbloqueados conforme desempenho;
- avaliação antes/depois;
- armazenamento anonimizado para pesquisa.
